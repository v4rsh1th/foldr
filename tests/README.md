# Foldr tests

| Command | Suite | Runner |
| --- | --- | --- |
| `npm run test:unit` | `tests/unit/` — pure logic | `node --test` |
| `npm run test:integration` | `tests/integration/` — real PDF operations and the server | `node --test` |
| `npm run test:browser` | `tests/browser/` — end-to-end in headless Chromium | Playwright |
| `npm run test:dist` | the browser suite against the built `dist/` (what Vercel serves) | Playwright |

All dev tooling (Playwright, `pdfjs-dist` for Node-side verification) is in `devDependencies`. The production app doesn't load it.

## Unit (`tests/unit/`)

- **page-ranges**: syntax, whitespace, dash variants, descending ranges, page 0, negatives, invalid syntax (never evaluated), empty entries, out-of-range pages, duplicate behaviour (rejected in extract mode, allowed when overlapping in range mode), chunking, labels.
- **page-order**: reordering (including the 3‑1‑4‑2 case), block moves, deletion, combined reorder and delete, rotation on top of existing rotation, reset, no input mutation, undo/redo, refusing empty exports.
- **filenames-format**: sanitising (paths, reserved and control characters, bidi overrides, HTML), unique names, default output names, byte/percent formatting, honest size-change direction.
- **scan**: perspective mapping, corner ordering and rotation, page detection on a synthetic photo (and no false positives on flat or noisy images), warping, shadow removal, black-and-white and colour filters, 1-bit packing.
- **validation-zip**: `%PDF-` signature detection, EOF marker, misleading MIME types, size limits, CRC-32, and a ZIP archive checked with `unzip -t`.

## Integration (`tests/integration/`)

Output files are reopened with **PDF.js** (independent of pdf-lib, which wrote them) to check page text, order, sizes and rotation.

- **operations**: inspection (including inherited rotation), feature detection, encrypted, corrupt, empty and truncated inputs; merge (order, sizes, orientation, rotation, images not rasterised, metadata, sources untouched); split (selection order, single page, every page, overlapping ranges, duplicates, rotation, out-of-range); organize/rotate (reorder, delete, combined, both directions, existing and inherited rotation, bookmarks and form fields kept, deleted pages removed from the file, empty and invalid plans).
- **compress**: text-heavy PDF shrinks more than 50% with identical text; duplicate images merged; an already-compact file is reported honestly; images untouched in lossless mode; the lossy pipeline (via a stub codec) chooses the right images, sizes and quality, keeps images when there is no gain, survives decode failures; PNG predictor decoding; unsafe images skipped.
- **scan**: page layout (auto, A4, Letter), JPEG and 1-bit pages read back with PDF.js, empty and broken input.
- **server**: CSP and security headers, 405 for upload-capable methods, service worker content-hash stamping, immutable vendor caching, manifest, no directory listing, dotfiles or traversal. The precache list must exactly match the app files, and a static scan of client code checks for network APIs, storage APIs, `eval` and HTML injection sinks.

Fixtures in `tests/fixtures/pdf/` are generated by `npm run fixtures` ([fixtures/generate.js](fixtures/generate.js) documents each one).

## Browser (`tests/browser/`, Playwright + Chromium)

Every test fails on any console error, page error, failed request, cross-origin request or non-GET request.

- **workflows**: tool navigation without reloads and with Back/Forward; handing files over from the home screen; unsaved-work warning (Stay/Leave); invalid, empty, encrypted and corrupt files; merge with reordering, renaming and download verification; split (extract, invalid-input messages, ranges, ZIP contents, every page); organize with toolbar, keyboard and mouse drag and drop, delete and undo, rotate and export; refusing to delete every page; lazy thumbnails for a 200-page file; rotate (inherited rotation, reset); compress (Balanced really shrinks, Smaller warns and converts lossless images, honest reporting when a file can't shrink); cancellation and retry.
- **scan**: importing a photo (edges found, cropped page shape), each look, corner editor, rotate/reorder/delete, unsaved-work warning, non-image files refused, capturing with Chromium's fake camera, photos dropped on the home screen offered only to the scanner.
- **pwa**: service worker install; offline reload, merge, previews and the offline fallback page; Cache Storage holds no documents; update flow (new version installs side by side, old cache removed after Reload); manifest icons. Also mobile layout (no horizontal scroll, controls of at least 44 px, tap to select) under Pixel 7 emulation, accessible names, roving tabindex, keyboard selection and moves, screen-reader announcements, dialog Escape and focus return, and filenames rendered as text.

## Manual checklist (not automated)

Run `npm start` (or `HOST=0.0.0.0 npm start` for phones; installing and offline use on a phone need HTTPS, for example through a tunnel).

- [ ] **Firefox and Safari (macOS and iOS):** each tool end to end; Compress offers lossy levels on Safari 16.4+.
- [ ] **Install** from Chrome's address bar or menu, and with "Add to Home Screen" on iOS/Android. The app opens standalone with the right icon and name.
- [ ] **Touch drag and drop:** on a real phone, drag a page by its grip and check that the page still scrolls when dragging elsewhere.
- [ ] **Screen reader:** with VoiceOver or NVDA, select files, hear validation results, move pages with Alt+arrows, and hear progress and "ready" announcements.
- [ ] **Real-world documents:** scanned PDFs (JPEG 2000/JBIG2), CJK text, form PDFs, signed PDFs (warning shown), owner-password PDFs (rejected), very large files (> 200 MB shows the confirmation).
- [ ] **Scanning on a real phone:** live outline follows the page; photos are sharp; Share opens the system sheet (iOS and Android); camera permission denied shows the fallback.
- [ ] **Low-memory device:** a large merge on an older phone either completes or fails with the memory message, without hanging.
- [ ] **iOS download behaviour** for single PDFs and ZIP.
- [ ] **DevTools → Network** while processing: only GET requests to the same origin, and none at all after the first load.
